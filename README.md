## วิธีใช้งาน

### 1. โคลนโปรเจกต์
```bash
git clone https://github.com/EmperorFiw/PromptPay-API.git
cd PromptPay-API
```

### 2. ติดตั้งแพ็กเกจ
```bash
npm install
```
### 3. รัน API Server
```bash
node server.js
```
